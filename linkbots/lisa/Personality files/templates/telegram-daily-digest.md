# Telegram daily digest template

Placeholders: `{{weekday_date}}`, work summary Yes/No, itemized calendar/tasks/email/unanswered, coding detail, battery block, fresh `{{pipeline_lines}}`, optional Main Approve ask.

## Freshness / omission

Same pipeline freshness as heartbeat. Battery always present on Telegram. Omit Main Approve unless Monday + Clear + claim rules.

## Determinism

Plain Telegram text. No fences. No unresolved placeholders.

Rendered by `renderTelegramDailyDigest`.
