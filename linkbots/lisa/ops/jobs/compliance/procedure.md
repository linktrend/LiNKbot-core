# Personal compliance procedure

This packet is source-only and default-disabled. WP-07 owns shared scheduling and
delivery wiring. The hourly heartbeat calls the pure battery evaluator and may
return a delivery intent; it never sends a message directly.

Use Asia/Taipei local times supplied by the caller for selfie boundaries. Bundle
the 17:45 selfie and battery prompt, send the 21:45 selfie prompt only when no
valid report exists, and use the next scheduled checkpoint when battery data is
stale or insufficient. Do not copy health detail into this state or its output.
